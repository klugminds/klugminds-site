# Stage

The V4 hero surface: a lit dark room rather than a navy rectangle.

- `Stage.tsx` — server wrapper composing grain, aurora pools, the woven grid,
  and (optionally) the signal field behind page content
- `SignalField.tsx` — the canvas particle network: seeded drifting nodes,
  teal links with warm accents, 150px pointer repulsion; pauses off-screen
  and on hidden tabs, draws one static frame under reduced motion
