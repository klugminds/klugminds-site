# Marketing components

Reusable section components for marketing pages. All copy is passed via props from `src/config/content/`.

| Component                | Purpose                                                     |
| ------------------------ | ----------------------------------------------------------- |
| `PageHero`               | Page header with eyebrow, title, description, optional CTAs |
| `SectionHeader`          | Section eyebrow, heading, and description                   |
| `FeatureGrid`            | Grid of feature/service/industry cards                      |
| `FeatureShowcaseSection` | Sticky panel or image with a stacked feature list beside it |
| `ProcessSteps`           | Numbered step cards                                         |
| `PrinciplesSection`      | Sticky summary with numbered principle list (Approach)      |
| `CtaSection`             | Contact or end-of-page call to action                       |
| `PartnerLogos`           | Partner grid with icon cards                                |
| `BlogCard`               | Blog post preview card                                      |
