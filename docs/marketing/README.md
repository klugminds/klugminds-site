## Purpose

This directory documents how Klugminds reaches its audience — market positioning, messaging frameworks, campaign plans, and content strategy. Marketing documentation aligns with product vision and brand guidelines to ensure a coherent public presence.

The company website in this repository is the primary marketing surface. Content strategy, SEO approach, and conversion goals documented here drive what the site publishes and how it is structured.

## Website Content Workflow

1. Content brief defined in this directory or linked from [product/](../product/).
2. Copy reviewed against [branding/](../branding/) voice guidelines.
3. Legal review for claims and compliance when needed ([legal/](../legal/)).
4. Content published via the website codebase in this repository.
5. Performance tracked against defined metrics.
