## Purpose

This directory defines who Klugminds is — mission, values, structure, and how decisions are made. It informs how the company presents itself on the website and how teams align on direction.

## Current Focus

Klugminds is in its foundation phase:

- **Company identity** — who we are and how we operate
- **Governance** — how decisions are made and recorded in [decisions/](../decisions/)

## Governance Framework

Decisions are classified by impact and reversibility:

| Category                  | Examples                                  | Process                                                     |
| ------------------------- | ----------------------------------------- | ----------------------------------------------------------- |
| Reversible, low impact    | Doc fixes, typo corrections               | Self-review or single approval                              |
| Reversible, medium impact | New standards, template updates           | One reviewer approval                                       |
| Hard to reverse           | Technology choices, security architecture | Decision record required                                    |
| Organizational            | Policy changes, role definitions          | Leadership review; document in [policies/](../../policies/) |
