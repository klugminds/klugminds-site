## Purpose

This directory helps new team members ramp up quickly by providing a structured path through Klugminds documentation, tools, and practices. It is the starting point for anyone joining the company or contributing to this repository for the first time.

Because `klugminds-site` is the company's first GitHub repository, onboarding here also covers how to work with the combined website and documentation codebase.

## Onboarding Checklist

- [ ] Repository cloned; editor configured per [.editorconfig](../../.editorconfig)
- [ ] Day 1–4 reading completed
- [ ] Understand the decision record process
- [ ] Know how to report security issues
- [ ] First documentation contribution merged
- [ ] Added to team communication channels
- [ ] Tool access provisioned
